# DIO 랜딩페이지 디자인

원본 기준: DIO 프로젝트 `docs/디자인 가이드.md` (2026-11-23 확인).

- 배경 `#F8F7FD`, 본문 `#1C1C1C`, 보조 본문 `rgba(28,28,28,.68)`, 주요 버튼 `#625BA7`, 보라 글자 `#514A96`, 경계 `#D9D8EA`를 사용한다.
- 보조 면 `#DDDAF5`, 마무리 면 `#F0ECFD`를 쓴다. 노랑 `#FEEF86`은 작은 스티커에만 쓴다.
- 로고·캐릭터는 원본 비율과 색을 유지한다. 본문 Pretendard, 예시 손글씨 고운돋움. 글꼴은 자체 호스팅한다.
- 랜딩 전용 배치: 본문 최대 1200px, 데스크톱 좌우 여백 40px, 모바일 18~20px. 넓은 화면은 두 열, 800px 이하 한 열. 구역 간격 116px, 모바일 76px.
- 본문 16px 이상, 보조 안내 12~15px. 본문 제목은 30~64px 사이 반응형. 주요 버튼 최소 52px, 아이콘·보조 버튼 최소 44px.
- 카드 모서리 20px, 다이어리 창 17px, 버튼 10px. 앱 내부의 UI 크기를 변경하는 규칙은 아니다.
- 첫 화면 연출은 한 차례만 재생하며 다시 보기 버튼을 제공한다. 동작 줄이기에서는 완성본을 즉시 표시한다. 내용을 감추는 스크롤 등장 효과는 사용하지 않는다.
- 실제 앱 화면과 랜딩 전용 예시를 문구로 구분한다. 검증되지 않은 사용자 수·성능·다운로드 링크·팀원 정보는 넣지 않는다.
- 키보드 포커스, 본문 건너뛰기, 토글 상태, 메뉴 상태, 확대 대화상자의 닫기와 Escape를 제공한다.
- 여러 페이지 구성: 홈·DIO 소개·주요 기능·이용 방법·브랜드 이야기는 각각 독립 HTML이며, 공통 상단 메뉴·하단 페이지 링크로 연결한다. 현재 메뉴는 `aria-current="page"`로 표시한다. 메뉴 이동에는 JavaScript가 필요하지 않다.
- 상세 페이지 상단은 홈 링크·현재 위치, 제목과 짧은 설명으로 구성한다. 본문 마지막에는 관련된 다음 페이지로 이어지는 행동을 둔다. 꾸미기 체험은 주요 기능 페이지에 둔다.
- 발표자료 반영: 홈 대표 문구는 `오늘의 순간을 나답게 기록하다`, 브랜드 풀네임은 `Decorate It Online`. 핵심 기능은 공동 편집·스티커 오리기·나만의 폰트 제작·동적 스티커로 소개한다.
- 만든 사람들은 별도 페이지에 이름·담당 역할을 표시한다. 팀원 사진이나 연락처는 임의로 추가하지 않는다.
- GIF 예시는 정지 프레임으로 시작하고 재생·정지 버튼을 항상 제공한다. 동작 줄이기 설정이 바뀌면 정지 프레임으로 복원한다.
- 홈 홍보영상: 대표 공유 카드를 포스터로 사용하고 16:9 플레이어에 원본 비율을 유지해 표시한다. 자동 재생 없이 `preload="none"`, `playsinline`, 기본 재생 컨트롤을 사용한다. 재생·일시정지 버튼과 새 창 보기 링크를 제공한다.
