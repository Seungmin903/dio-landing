팀 소개의 프로필 일러스트는 사용자 승인에 따라 발표자료 42장의 이미지와 이름 배치를 기준으로 연결했다. 신승민은 개별 그림, 정영주·기하영·전소연·장우창은 시트의 오른쪽 위·왼쪽 아래·오른쪽 아래·왼쪽 위 그림을 사용한다. 시트 원본은 변경하지 않고 CSS로 영역을 표시한다. 최영우·황민희는 사용자 요청에 따라 이니셜을 유지한다.

2026-11-23 사용자가 제공한 `15기_자율PJT_영상 포트폴리오_F106.mp4`를 홍보영상으로 공개해 달라고 요청했다. 원본을 변경하지 않고 `assets/video/dio-promo.mp4`로 게시했다. 파일 크기는 24,061,163바이트, 재생 시간은 약 62.5초이며 MP4(H.264/AAC)이다. 홈에 재생 구역을 두고 모든 페이지 하단에서 연결한다.

손글씨 36자→한글 11,172자 생성, Android·iOS 앱의 생성 지원, 이미지·GIF 내보내기 설명은 DIO 프로젝트의 `docs/personal-handwriting-font.md`와 `exec/4_시연_시나리오.md`로 교차 확인했다. 폰트 생성 화면은 `exec/images/25_손글씨폰트_입력.png`를 사용했다.

발표자료의 SNS 수치·부스 방문자 수는 발표 당시 수치이므로 현재 성과처럼 게시하지 않았다. 클라우드 구독 가격·사용자 목표·공모전·C2C·투자 유치는 현재 제공 기능으로 게시하지 않았다. 스토어 출시 문구만으로 앱 배포 URL을 추정하지 않았다. 슬라이드 안의 연출 메모는 사이트 변경 지시로 취급하지 않았다.

## 2026-11-25 흐름 개편
- 새 ZIP의 43장 발표자료를 확인했다. 감사 인사, 발표용 연출 지시, 날짜가 있는 지표 및 향후 수익 계획은 공개 서비스 기능으로 옮기지 않았다.
- https://patensify.com/en/ 의 큰 대표 문구, 넓은 여백, 제품 사용 과정을 따라가는 설명 흐름을 참고했다. 해당 사이트의 문구·이미지·코드는 복제하지 않았다.
- DIO의 기존 앱 화면·홍보영상·팀원 일러스트를 유지하고 홈의 읽기 순서와 상세 페이지 간 연결을 재구성했다.

- 마스코트 이름·외형은 사용자 확인 기준: 노란 캐릭터는 모아, 눈사람 캐릭터는 디오. 브랜드 소개에 각각 명시하고 홈·브랜드 이미지 대체 텍스트에도 반영했다. 별도 성격·세계관은 추가하지 않았다.

- Calendly(https://calendly.com/)의 제품 선택 탐색과 넓은 대표 영역을 참고해 홈·주요 기능을 재작성했다. 외부 코드·이미지·문구를 복사하지 않았다. 실제 스티커 패널 화면은 프로젝트 exec/images/14_편집_스티커.png를 사용했다. 마스코트의 개별 소개, 팀원 7명, 홍보영상은 유지했다.
