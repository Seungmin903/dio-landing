함께 기록하기

같은 페이지에,
각자의 이야기를.

친구를 초대해 같은 다이어리를 함께 편집해요. 사진 위에 텍스트와 손그림을 더하며 하나의 기록을 완성할 수 있어요.

  • 친구를 다이어리에 초대
  • 같은 페이지에 텍스트·손그림 더하기
  • 완성한 페이지를 이미지로 내보내기

사진에서 꺼내 쓰기

내 스티커로.

사진에서 원하는 대상을 선택하면 AI가 배경을 분리해줘요. 오린 이미지를 내 스티커로 저장하고 페이지에 붙여보세요.

  • 사진 속 원하는 대상 선택
  • AI로 배경을 분리해 오리기
  • 내 스티커로 저장해 다시 사용

내 글씨로 쓰기

직접 쓴 36자에서
나만의 한글 폰트로.

안내된 36자를 손으로 쓰고 샘플을 확인해요. AI가 만든 폰트를 다이어리 텍스트에 적용하면 내 글씨로 기록할 수 있어요.

  • 36자 손글씨 입력과 샘플 확인
  • 한글 11,172자를 담은 폰트 생성
  • Android·iOS에서 폰트 생성
